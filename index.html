InflmaHub

InflmaHub는 인플루언서 협업 담당자가 자기 Windows PC에 설치해 쓰는 개인용 프로그램입니다. Gmail, Instagram DM, 카카오톡으로 나뉘어 있는 협업 대화를 한 화면에 모아 보고, 답장이 필요한 대화와 일정을 놓치지 않도록 돕습니다. 소수 지인에게만 개인적으로 배포되며, 판매하거나 광고하지 않습니다.

Google 사용자 데이터 이용

  • 요청하는 권한: gmail.readonly(협업 메일 읽기), gmail.send(사용자가 직접 [발송]을 누른 답장 보내기), openid(Google 계정 구분)
  • 이용 목적: 협업 메일을 통합 수신함, 인플루언서별 대화 기록, 답장·일정 리마인드에 표시하는 것에만 씁니다.
  • 저장 위치: 메일은 Google에서 사용자 PC로 직접 받아, 그 PC에만 암호화(AES-256)해 저장합니다. 운영자 서버가 없고, 개발자는 메일이나 로그인 토큰을 받지 않습니다.
  • AI 분석: 사용자가 따로 동의한 경우에만, 사용자 본인의 AI API 키로 필요한 최소 내용을 보냅니다. Google 사용자 데이터를 광고나 AI 모델 학습에 쓰지 않으며, 판매하거나 다른 곳에 넘기지 않습니다.
  • 삭제: 앱 설정에서 언제든 연결 해제(Google 권한 취소 포함)와 데이터 삭제를 할 수 있습니다.

InflmaHub가 Google API로 받은 정보를 사용하고 다른 앱으로 전송하는 방식은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
