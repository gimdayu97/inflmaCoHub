Cohubee 개인정보처리방침

시행일: 2026-11-16 (앱 버전 0.6.0)

Cohubee(이하 "앱")는 인플루언서 협업 대화를 관리하기 위해, 사용자 본인이 자기 PC에 설치해 쓰는 개인용 Windows 프로그램입니다. 운영자 서버가 없고, 개발자는 사용자의 데이터를 받거나 볼 수 없습니다.

1. 앱이 다루는 정보

출처정보언제
Gmail (사용자 본인 계정)메일 제목, 보낸 사람·받는 사람, 본문(인용된 이전 메일은 제외), 보낸 시각, 메일·스레드 ID, Google 계정 식별자(sub), 메일 주소사용자가 동의하고 Google 계정을 연결한 뒤, 동기화할 때
Instagram DM (사용자 본인 프로페셔널 계정)대화 상대 사용자명, 메시지 내용과 시각, Instagram 계정 식별자(user_id)와 사용자명사용자가 동의하고, 본인 Meta 앱에서 만든 토큰으로 연결한 뒤
카카오톡사용자가 저장해서 가져온 대화 파일의 내용. 자동 수집은 카카오 정책 확인 전까지 잠겨 있음사용자가 파일을 가져오거나 승인했을 때
사용자 입력인플루언서 메모, 협업 단계, 설정사용자가 입력할 때

Gmail 권한: gmail.readonly(메일 읽기), gmail.send(사용자가 [발송]을 누를 때만 답장 보내기), openid(계정 구분용 식별자).

2. 이용 목적

통합 수신함, 인플루언서별 타임라인, 협업 상태·요약, 리마인드, 답장 초안 작성 등 앱 화면에 보이는 기능에만 사용합니다. 광고, 판매, 프로파일링, 모델 학습에는 사용하지 않습니다.

3. 저장 위치와 보호

  • 모든 데이터는 사용자 PC의 %APPDATA%\InflmaHub에 저장됩니다.
  • 데이터베이스와 백업 파일은 AES-256으로 암호화됩니다(SQLCipher). 암호화 키는 Windows 자격 증명 관리자에 Windows 사용자별로 보관됩니다.
  • Google·Instagram 인증 토큰, 사용자가 직접 등록한 OAuth 클라이언트 정보, AI API 키는 Windows 자격 증명 관리자에만 저장됩니다. DB, 로그, 화면에는 나오지 않습니다.
  • 여러 Google 계정을 번갈아 쓰면, 전환해 둔 계정의 인증 토큰도 연결 해제나 전체 삭제 전까지 자격 증명 관리자에 보관됩니다. 계정별 메일은 서로 섞이지 않게 따로 저장됩니다.
  • 설치 파일에 들어 있는 기본 Google 로그인 설정(데스크톱 앱 클라이언트 ID)은 사용자 정보가 아니며, 프로그램 설치 폴더에 있습니다.
  • 앱 로그에는 메시지 내용을 기록하지 않습니다.

4. 외부로 전송되는 경우

받는 곳보내는 내용조건
Google (Gmail API)메일 조회·발송 요청Gmail 연결 시
Meta (Instagram API)DM 조회·발송 요청Instagram 연결 시 (사용자 본인 Meta 앱의 토큰)
선택한 AI 제공자 (Anthropic 또는 OpenAI)분석이 필요한 새 메시지(연락처 가림, 메시지당 최대 1,500자)와 기존 요약사용자가 채널별로 AI 전송에 동의하고 AI를 사용할 때만. 사용자 본인 API 키로 직접 전송
  • AI 전송 전에 앱의 "보낼 내용 보기"로 실제 전송 내용을 확인할 수 있습니다.
  • 두 AI 제공자는 API로 받은 데이터를 기본적으로 모델 학습에 쓰지 않으며, 남용 방지를 위해 최대 30일 보관할 수 있다고 공개하고 있습니다.
  • Anthropic: Commercial Terms, privacy.claude.com
  • OpenAI: API 데이터 정책
  • OpenAI를 쓸 때는 OpenAI 계정에서 "데이터 공유(share data)" 옵트인을 켜지 마세요.
  • Anthropic 콘솔의 피드백 제출 기능도 쓰지 마세요.

Google 로그인 설정(OAuth 클라이언트): 기본 설치 파일은 개발자가 만든 Google Cloud 프로젝트의 '데스크톱 앱' 클라이언트로 Google 로그인 화면을 엽니다. 이 설정은 Google에 "어떤 앱이 권한을 요청하는지"를 알리는 용도일 뿐입니다. 로그인 토큰은 Google에서 사용자 PC로 직접 전달되어 Windows 자격 증명 관리자에만 저장되고, 메일도 Google에서 사용자 PC로 직접 받습니다. 개발자는 토큰이나 메일 내용을 받지 않으며, Google Cloud 콘솔에서 사용자 수와 API 호출 수 같은 집계 정보만 볼 수 있습니다. 고급 설정에서 본인 프로젝트의 클라이언트로 바꿀 수 있습니다.

Google 사용자 데이터 관련: Cohubee가 Google API로 받은 정보를 사용하고 다른 곳으로 전송하는 방식은 Limited Use 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

5. 보관 기간과 삭제

  • 보관 기간: 기본은 사용자가 삭제할 때까지입니다. 설정에서 Gmail 메일 보관 기간(일)을 정하면 그보다 오래된 메일은 자동 삭제됩니다.
  • Gmail 연결 해제: Google 권한을 취소하고 토큰을 지웁니다. 그 계정의 메일은 보관 또는 삭제 중 선택할 수 있습니다.
  • 계정별 데이터 삭제: 설정 → Gmail → 계정 목록에서 할 수 있습니다.
  • 전체 삭제: 설정 → 백업·복구·삭제 → 모든 데이터와 키 삭제. 키까지 삭제하면 연결된 모든 Google 계정의 권한 취소를 Google에 요청하고 토큰을 지웁니다.
  • Google 쪽 권한은 Google 계정 → 보안 → 타사 앱 및 서비스에서도 취소할 수 있습니다.
  • 앱을 제거해도 %APPDATA%\InflmaHub는 남습니다. 완전히 지우려면 앱에서 전체 삭제를 먼저 하세요.

6. 사용자 권리

사용자는 언제든 연결 해제, 동의 철회(AI 전송 포함), 데이터 열람(앱 화면), 삭제를 할 수 있습니다. 동의를 철회하면 그 즉시 해당 전송이 중단됩니다.
